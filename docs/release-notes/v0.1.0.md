# 特产采集手账 v0.1.0

首个三端版本，支持在 Web、Windows 和 Android 上管理角色区域特产采集规划与 46 小时刷新冷却。

## 本次提供

- Web、Windows 与 Android 三端使用；
- Windows NSIS 安装包和便携版 EXE；
- 已签名的 Android `arm64-v8a` APK；
- 导入、导出 JSON 备份，并可直接复制 JSON；
- 通过 QQ、微信等工具发送 JSON，在其他设备导入规划和冷却记录。

## 数据迁移

1. 在原设备点击 `导出`，选择 `复制 JSON`；
2. 将完整 JSON 作为纯文本发送到目标设备；
3. 在目标设备点击 `导入`，选择 `粘贴 JSON`；
4. 粘贴并确认导入。

导入会覆盖目标设备现有规划和冷却记录，请先备份需要保留的数据。

## 下载说明

- Windows：优先使用 NSIS 安装包；便携版 EXE 可直接运行。
- Android：下载并安装标记为 `arm64-v8a` 的 APK。
