# 特产采集手账 v0.1.2

角色与区域特产图鉴已更新至《原神》`7.0.0` 数据，并补齐至冬地区的筛选与角色归属。

## 数据更新

- 图鉴更新至 `7.0.0`：收录 120 名角色和 59 种区域特产。
- 新增阿罗夏与奥黛塔，以及对应特产植绒草、霜仙花。
- 数据同步改用 AnimeGameData，后续更新不再依赖 genshin-db。

## 修复与优化

- 角色选择器新增“至冬”筛选，位于“挪德卡莱”和“其他”之间。
- 修正奥黛塔与桑多涅的地区归属；两人现在会显示在“至冬”筛选中。

## 下载说明

- Windows：优先使用 NSIS 安装包；便携版 EXE 无需安装，可直接运行。
- Android：请下载标记为 `arm64-v8a` 的 APK。
