# 特产采集手账 v0.1.1

这一版正式完善 Web、Windows 和 Android 三端交付。现在可以在任意一端保存规划，通过 JSON 备份迁移到另一台设备继续记录采集冷却。

## 三端使用

- Web：继续通过网页使用，无需安装；
- Windows：提供 NSIS 安装包和可直接运行的便携版 EXE；
- Android：提供已签名的 `arm64-v8a` APK。

## 规划迁移

在原设备点击 `导出`，选择 `复制 JSON`，将完整 JSON 作为纯文本通过 QQ、微信等工具发送；在目标设备点击 `导入`，选择 `粘贴 JSON` 后确认即可恢复规划和冷却记录。

导入会覆盖目标设备已有数据，请先导出需要保留的内容。

## 修复

- 修复手账双页中缝只显示在初始可视区域的问题；滚动浏览长内容时，中缝现在会持续延伸。
- 修复 Windows CI 签名时中文 APK 文件名可能导致 Android 发布构建失败的问题。
- 修复发布流程中便携版 EXE 在 Android 构建后被清理、未上传到 Release 的问题。

## 下载说明

- Windows：优先使用 NSIS 安装包；便携版 EXE 无需安装，可直接运行。
- Android：请下载标记为 `arm64-v8a` 的 APK。
